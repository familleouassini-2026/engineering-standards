# Project Documentation Language

All project and engineering documentation MUST be written in English.

This includes:
- README files
- Kiro Steering
- Feature Specs
- requirements.md
- design.md
- tasks.md
- architecture documentation
- ADRs
- business/domain documentation
- security documentation
- runbooks
- migration documentation
- test plans
- audit reports
- technical implementation plans
- architecture/business-behavior code comments

User-facing application content may use the language required by the product.

Internal engineering documentation remains in English for team readability, consistency, reuse, and AI-agent context quality.
